# طريق نحو أفضل 🚀

**Tariq Nahw Afdal** - A habit tracking and personal development app

## 🎯 الميزات الرئيسية

- 🔥 **السلسلة المتتالية**: تتبع التزامك اليومي
- 🎯 **إدارة العادات**: راقب عاداتك المختلفة
- 📊 **نسبة الإنجاز**: شاهد تقدمك يومياً
- 🏆 **نظام المستويات**: ارتقِ من مستوى إلى آخر
  - 🌱 البداية
  - ⚡ الانضباط
  - 🛡️ القوة
  - 🏆 الإنجاز
- 🎯 **التحديات**: انضم لتحديات 7 و 30 يوم
- 📚 **التعلم**: تطور مهاراتك في اللغات والبرمجة

## 🛠️ التقنيات المستخدمة

- **React 18** - مكتبة UI
- **TypeScript** - نوع آمن
- **Vite** - بناء سريع
- **Tailwind CSS** - تصميم
- **React Router** - التنقل
- **Zustand** - إدارة الحالة

## 📦 التثبيت

```bash
npm install
npm run dev
```

## 🎨 التصميم

- **النمط**: غامق وبسيط ورياضي
- **الألوان**: رمادي داكن مع نقاط إضاءة زرقاء/بنفسجية
- **التوجيه**: من اليمين إلى اليسار (RTL)
